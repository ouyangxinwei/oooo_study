# 玩法与系统说明

## 1. 游戏目标

操纵冒险者穿过三个区域，击败沿途敌人并进入守门者大厅，最终击败 Boss。当前版本是可交互原型，重点是验证基础动作、攻击判定和手机操作。

## 2. 操作说明

| 操作 | 效果 | 注意事项 |
|---|---|---|
| 左 / 右 | 水平移动 | 可按住持续移动 |
| 跳跃 | 离开地面并受重力影响 | 当前仅在 `onGround` 时起跳 |
| 挥鞭 | 近距离攻击 | 具备前摇、有效帧、收招；一次挥击对同一目标最多命中一次 |
| 灵击 | 发射远程投射物 | 每次消耗 10 点灵力；灵力不足时不能发射 |
| 下蹲 | 当前按钮/键位已预留 | 当前尚未实现独立下蹲动作 |

## 3. 角色移动与平台

玩家有位置、速度、重力、朝向和落地状态。`update(dt)` 先读取输入，再应用速度和重力，之后检查玩家是否从上方落到平台顶面。平台定义在 `index.html` 的 `platforms` 数组。

如果新增平台：

1. 在 `platforms` 数组增加 `{x, y, w}`。
2. 让平台位于世界坐标范围内。
3. 检查角色是否能跳到平台上，以及平台之间是否有无法跨越的空隙。
4. 在手机实际操作中测试跳跃容错。

## 4. 角色动画

当前角色是 Canvas 像素块绘制，不是精灵图序列。`drawHero()` 根据玩家状态调整：

- 跑步时腿部摆动和身体起伏；
- 披风有轻微摆动；
- 挥鞭时按攻击进度绘制不同的鞭子轨迹；
- 受伤无敌时进行闪烁；
- 灵击时显示短暂的发光提示。

要升级为真正逐帧动画，可先准备原创透明 PNG 精灵图或 sprite sheet，再按帧宽高、动画状态和帧率绘制；同时保留现有碰撞盒，避免视觉帧变化导致物理盒意外变化。

## 5. 挥鞭判定调节

相关字段与函数位于 `index.html`：

- `player.attackDuration`：一次挥鞭总时长，当前为 `0.34` 秒。
- `player.attackRange`：攻击范围，当前为 `43` 个逻辑像素。
- `attackHitbox()`：有效帧窗口和矩形位置。
- `applyWhipHits()`：敌人与 Boss 的伤害处理。
- `player.attackHitIds`：本次挥击已命中的目标 ID 集合。

调节建议：

- 攻击太快：适度增加 `attackDuration`，并同步观察动画。
- 攻击距离太短：增加 `attackRange`，再检查视觉鞭子终点。
- 攻击看似命中却无伤害：检查有效帧窗口、攻击盒的 y/宽高、朝向和敌人碰撞盒。
- 同一次攻击重复伤害：检查是否在每次挥击开始时重置集合、是否为每个目标使用稳定且唯一的 ID。
- Boss 伤害不平衡：普通敌人与 Boss 的扣血数值是分别设置的，应独立调整。

## 6. 生命、灵力和敌人

- 玩家生命值为 100，灵力为 30。
- 普通敌人有独立 HP 和类型；靠近玩家时会改变移动方向并接近玩家。
- 玩家碰到敌人或 Boss 会受到伤害；玩家受伤后有短暂无敌与击退。
- 击败普通敌人可增加战利品计数，并按当前规则回复少量生命/灵力（不同击败路径的回复逻辑可能不同）。
- 灵击投射物可伤害敌人与 Boss；Boss 也会发射敌对投射物。
- 玩家进入世界后段时 Boss 出现。击败 Boss 触发胜利界面，生命值归零触发失败界面。

## v0.22：Boss 分阶段战斗
- Boss HUD 显示实时生命值与当前阶段。阶段阈值为 66% 和 33%。
- 阶段 I 使用高/低位灵弹；阶段 II 加入冲刺与范围攻击；阶段 III 加快攻击并召唤最多 4 个亡灵援兵。
- Boss 胜利奖励为金币 +100、生命药水 +1、灵力药水 +1，并优先赠送一件尚未收集的装备；随机掉落机制不变。
- 如果更新后仍看到旧版，请关闭已打开的 PWA，再重新打开；必要时清除该站点缓存后重新加载。

## V23：角色成长与状态系统
- 击败敌人获得经验：蝙蝠 25、骷髅兵 35、法师 40、重甲骑士 60；守门者 300。
- 经验达到升级阈值时自动升级，每级生命上限 +10、灵力上限 +5，并恢复相应数值。升级后获得 2 点属性点。
- 打开「查看物品清单」，在「角色状态与成长」查看等级、经验、可用属性点、生命/灵力、攻击、防御和经验条；点击「攻击 +1」或「防御 +1」分配属性点。
- 攻击成长影响挥鞭和灵击伤害；防御成长降低受到的伤害。生命/灵力 HUD 和药水恢复适配动态上限。


## V24：存档与继续冒险

- 首次游玩点击「新游戏」。如果已有有效存档，游戏会先确认是否覆盖。
- 有效存档存在时，标题页会显示「继续冒险」，用于恢复最近一次保存的进度。
- 游戏约每 5 秒自动保存一次；暂停、离开页面、开启宝箱、拾取物品、角色升级/加点、换装和结局时也会保存。
- 存档包含角色成长、金币与药水、装备收藏/穿戴、已开启宝箱、敌人/Boss 进度及场景掉落物。
- 存档仅属于当前浏览器与网站。清除浏览数据、无痕窗口或更换设备后，存档可能不存在。
- 若存档损坏或版本不兼容，游戏会提示无法恢复；请开始新游戏。演示模式不会覆盖玩家存档。


## V25：隐藏房间与秘密通道

在图书馆与钟楼交界附近寻找发出青色微光的隐秘石门。角色靠近后按 ↑ 进入「月影密室」，探索额外平台并开启隐藏宝箱；从密室另一侧的石门按 ↑ 可返回古堡。隐藏宝箱奖励包括金币、灵力药水和月光吊坠。角色位置、发现状态和宝箱进度会随自动存档保存。
