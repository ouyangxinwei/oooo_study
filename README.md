# 月影古堡 Moonlit Keep

> **当前版本 V42：修复通关演示卡点并覆盖八关路线。** 八关专属地图、路线与探索目标完整保留。


**原创 2D 像素风横版动作探索游戏 Demo｜V42｜Android PWA**

《月影古堡》是一个使用原生 HTML、CSS、JavaScript 和 Canvas 编写的轻量游戏原型。支持触屏与可自定义键盘操作，包含移动、跳跃、近战挥鞭、远程灵击、敌人、Boss、生命/灵力 HUD、默认关闭、可手动开启的原创合成古堡背景音乐，以及基础 PWA 离线缓存配置。角色、名称、地图和视觉表现均为原创演示内容，不包含《恶魔城》原作素材。

## 快速开始

1. 下载并解压项目 ZIP，或克隆本仓库。
2. 在浏览器中通过本地静态服务器或 HTTPS 网站打开 `index.html`。
3. 手机推荐横屏。Android Chrome 打开网站后，可从浏览器菜单选择“安装应用”或“添加到主屏幕”。
4. 首次访问请保持联网，等待 Service Worker 缓存完成。

> 直接以 `file://` 打开 HTML 可以用于部分核心玩法的快速查看，但 PWA 安装和 Service Worker 通常需要 HTTPS 或 localhost。

## 当前功能

- 八关连续关卡：月蚀前庭、亡者墓园、遗忘图书馆、逆时钟楼、冰封回廊、蔓生圣坛、裂隙深渊、月蚀王座；每关有独立地图路线、主题色调与专属 Boss
- 左右移动、跳跃、平台落地和镜头跟随；高台实体侧面碰撞，较高高台可抓边攀爬
- 近战挥鞭（站立/下蹲）与远程灵击；前摇、有效帧、收招，单次挥击对同一目标只命中一次
- 四类敌人：蝙蝠、骷髅兵、远程法师、重甲骑士；具备巡逻、发现、追击、攻击和返回行为，各有不同弱点
- 八名 Boss 三阶段战斗（试探→狂袭→绝境），含灵弹、冲刺、范围攻击、召唤亡灵等攻击模式
- 角色成长系统：经验/等级/属性点分配（攻击/防御），升级提升生命与灵力上限
- 装备系统：武器、防具、饰品三槽位，共六件装备，影响攻击/防御/移动速度
- 探索元素：宝箱、地图机关（关闭危险区）、探索目标、隐藏秘密通道（月影密室）
- 版本化本地存档：自动保存到 localStorage，支持继续冒险；存档含版本校验与字段白名单验证
- 触屏虚拟按键、可自定义键盘操作
- PWA manifest、应用图标、Service Worker 静态缓存、离线运行
- 通关演示（自动操作 + 无限 HP/MP）、作弊功能（无限生命/灵力）、原创合成背景音乐

## 当前限制

- 这是单文件 JavaScript 的演示原型，尚未拆分成模块或使用外部游戏引擎。
- 美术为 Canvas 像素几何绘制，并非完整逐帧精灵图动画。
- 目前主要进行 JavaScript 语法检查与静态回归测试；尚未完成真实 Android 设备、不同浏览器和全面玩法的人工回归测试。
- 浏览器、系统版本、屏幕比例和 PWA 安装提示可能造成表现差异。
- 存档仅存在当前浏览器/设备的 localStorage 中，不是云同步；清理网站数据或更换浏览器/设备会导致存档不可用。

## GitHub Pages 发布

1. 在 GitHub 新建仓库，例如 `moonlit-keep`。
2. 上传本项目所有文件和 `docs/` 文件夹，保持目录结构不变。
3. 打开仓库 **Settings → Pages**，选择从 `main` 分支的根目录（`/(root)`）发布。
4. 等待 GitHub Pages 提供 HTTPS 地址。
5. 在 Android Chrome 打开地址，先在线运行一次，再从浏览器菜单安装/添加到主屏幕。

详细步骤和缓存更新办法见[部署与故障排查](docs/部署与故障排查.md)。

### 键盘按键自定义
点击页面右上角的“按键设置”，可以查看并更改左移、右移、跳跃、下蹲、挥鞭攻击和灵击的键盘绑定。点击某项当前按键后，直接按下希望绑定的新键即可。按键设置保存在当前浏览器中；“恢复默认”可还原为方向键移动/跳跃、J 挥鞭、K 灵击。触屏按钮也会显示当前键盘绑定。

### v0.3 角色动画
当前角色已加入程序绘制的站立、奔跑、跳跃、下落、攻击、受伤和死亡动画状态。动画使用 Canvas 像素矩形绘制，不依赖外部精灵图；后续可替换为逐帧精灵图以获得更丰富的动作细节。


## 守门者双高度攻击（新版）
- 守门者会交替发射低位蓝色灵弹与高位橙色灵弹。
- 看到低位蓝弹时按住「下蹲」；看到高位橙弹时及时「跳跃」。
- 战斗中会显示攻击高度提示；观察颜色和高度，提前选择动作。


### 背景音乐默认设置
打开游戏或点击「开始冒险」时，背景音乐默认保持关闭，不会自动播放。需要音乐时，可点击页面顶部的「♫ 音乐：关闭」按钮手动开启；设置会在当前游戏页面内生效。

## 下蹲攻击（v0.10）
- 按住下蹲键（↓），同时按攻击键（J/挥鞭）可进行低位鞭击。
- 下蹲攻击的判定区域更低、攻击距离略短，适合攻击低处目标；站立攻击保持原有动作与判定。


## v0.11 — 当前关卡任务
- HUD 下方显示当前关卡任务与进度条。
- 清除小兵对应 50% 进度；Boss 战斗占 40%；可选探索目标占 10%。
- Boss 被击败后完成度显示 100%，并将任务状态标记为「全部完成」。
- 通过近战或灵击击败小兵都会正确计数；重新开始会清空任务进度。


## v0.12 — 作弊功能
- 点击顶部「作弊」按钮，可单独开启「无限生命」或「无限灵力」，也可同时开启。
- 无限生命：受到攻击不扣血、不死亡；如果已经死亡，可开启后恢复生命并继续。
- 无限灵力：灵力维持满值，灵击不消耗灵力。
- 点击「完成」关闭面板；作弊状态只在当前页面会话中有效，刷新页面后恢复关闭。


## V13：暂停与重新开始
- 点击顶部「Ⅱ 暂停」或按 Esc 暂停游戏；暂停时当前关卡进度会保留。
- 点击「继续游戏」或顶部「▶ 继续」恢复游戏。
- 暂停面板提供重新开始入口，可从关卡起点重新挑战并重置敌人、Boss、战利品及任务进度。

## V14：简化顶部操作区
- 移除顶部独立的「↻ 重开」按钮。
- 暂停面板中的「继续游戏」和「重新开始」两个功能保持不变；胜利/失败界面的再次挑战入口也保留。


## 通关演示（v0.19）
点击顶部「▶ 通关演示」或标题画面中的「观看通关演示」，游戏会从关卡起点自动演示移动、平台跳跃/攀爬、小兵战斗、守门者战斗及通关结算。演示会重置当前进度，并临时使用无限生命与灵力以确保流程能够展示；演示结束后会恢复开始前的作弊开关状态。


## V17：探索奖励与装备
- **宝箱**：关卡沿途有多个宝箱。靠近后按键盘 ↑ 或触屏跳跃键开启，拾取掉落物即可收集。
- **奖励**：金币、生命药水（恢复 30 HP）、灵力药水（恢复 15 MP），以及武器、防具和饰品。药水在「背包」中使用。
- **装备**：点击顶部「🎒 背包」，查看装备和属性并点击「装备」切换。武器提升攻击力；防具降低受到的伤害，但部分重甲会减速；饰品可提升攻击、防御或移动速度。
- **本局重置**：重新开始会重置宝箱开启状态、金币、药水、装备和地面掉落物。


## V18：怪物掉落率调整
- 每只被击败的小怪独立进行一次掉落判定，基础掉落率暂定为 **50%**；守门者 Boss 被击败时也进行一次判定。
- 成功掉落时随机产生金币、生命药水、灵力药水或装备，物品会出现在怪物倒下的位置附近，接触即可拾取。
- 装备掉落优先选择背包尚未拥有的装备；如果装备已收集齐，则改为掉落金币或药水。
- 原有场景宝箱仍可正常开启；怪物掉落不需要开启宝箱。掉落几率集中定义在 `MONSTER_DROP_CHANCE = 0.5`，方便后续调整。

## v0.22 Boss 战斗规则
- HP > 66%：阶段 I，交替发射高位/低位灵弹。
- HP ≤ 66% 且 > 33%：阶段 II，加入冲刺与范围攻击。
- HP ≤ 33%：阶段 III，攻击节奏更快，并可召唤最多 4 个援兵。
- 胜利奖励：金币 +100、生命药水 +1、灵力药水 +1；如果仍有未收集装备，额外获得其中一件。原有 Boss 50% 随机掉落仍然保留。
